# Agent Instructions

## Package Managers

- PHP: **Composer**; JS: **npm** (`package-lock.json`).

## Commands

PHP tests need the Sail stack running (`docker compose up`): they use the Sail Postgres `testing` database.

| Task                  | Command                                              |
| --------------------- | ---------------------------------------------------- |
| Test file             | `./vendor/bin/sail artisan test tests/Feature/X.php` |
| Test by name          | `./vendor/bin/sail artisan test --filter='name'`     |
| Format PHP file       | `./vendor/bin/sail pint path/to/File.php`            |
| PHP static analysis   | `./vendor/bin/sail composer types:check`             |
| Frontend lint/format  | `npm run check` (`npm run check:fix` to fix)         |
| Frontend types        | `npm run types:check`                                |
| Frontend tests        | `npm test`                                           |
| Full CI (before a PR) | `./vendor/bin/sail composer ci:check`                |

## Key Conventions

- `resources/js/actions`, `resources/js/routes`, `resources/js/wayfinder` are generated by the Wayfinder Vite plugin; regenerate with `npm run build` or `npm run dev`.
- Add schema changes as new migrations; merged migrations are fixed.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for ablunier/pixelforge-assessment (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default label names: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.

## Commit Attribution

AI commits MUST include:
